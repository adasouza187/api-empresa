# API Empresa

API REST para gerenciamento de empresas.

## Tecnologias
- Node.js
- Express

## Como rodar localmente

```bash
git clone https://github.com/adasouza187/api-empresa.git
cd api-empresa
npm install
```

Crie um arquivo `.env` com base no `.env.example` e rode:

```bash
npm start
```
